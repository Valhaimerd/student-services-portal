## 2. TypeScript notes

### Generics

`ApiResponse<T>` preserves the type of its `data` value. For example, `ApiResponse<Student>` guarantees one student while `ApiResponse<Student[]>` guarantees an array of students. This is safer than `data: any` because the compiler can check property access and report incorrect assumptions instead of disabling type checking.

### Runtime validation

A TypeScript interface is removed during compilation, so it cannot inspect data received while the program is running. External API or user input is therefore accepted as `unknown` and checked before it is treated as a `Student`. The validator confirms the required property types and limits `status` to the supported values.
